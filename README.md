A weather app where users can fetch data and visualize it in graphs and maps.

This app uses [Visual Crossing's weather API](https://www.visualcrossing.com/weather-api/).

If you plan on cloning this project, you will need to create a `.env` file with these values:

```bash
  NEXT_PUBLIC_API_KEY=<Your visualcrossing API key>
  NEXT_PUBLIC_BASE_URL=https://weather.visualcrossing.com/VisualCrossingWebServices/rest/services/timeline/
```
